## Issues & Fixes

1. **Smoke test didn't compile** — imports at line 51, mid-file. Cause:
   Kotlin only allows imports in the header. Fix: moved to top of file.
2. **`firebase.auth.ktx` imports unresolvable** — Cause: Firebase BOM 34
   deleted the `-ktx` artifacts; the KTX API moved into the main modules.
   Fix: `com.google.firebase.Firebase` + `com.google.firebase.auth.auth`.
3. **`libs.firebase.analytics` undefined** — dependency referenced without a
   catalog alias. Fix: added the alias (BoM-managed, no version).
4. **Anonymous auth failed with `CONFIGURATION_NOT_FOUND`** — Cause: the
   Anonymous sign-in provider was not enabled in the Firebase console (SDK
   and json were fine — the call reached the backend). Fix: enabled
   Anonymous + Email/Password under Authentication → Sign-in method; re-test
   logged `Auth Success!`.
