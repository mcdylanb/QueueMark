# Development Journal

One Markdown file per working session, named `YYYYMMDD.md`. Each entry has, in
order: **Summary** (what the session accomplished), **Log** (chronological
bullets of what happened, including decisions and why), **Issues & Fixes**
(symptom → cause → fix), **Setup / Reproduce** (exact commands), and
**Next Action Items**.
