## Issues & Fixes

1. **Hilt plugin crash at configuration** — `Android BaseExtension not
   found`. Cause: Hilt 2.57.2 uses an API AGP 9 removed. Fix: Hilt 2.60.1.
2. **KSP refuses AGP 9's built-in Kotlin** — hard RuntimeException with
   prescribed fix. Cause: KSP (required by both Hilt and Room) has no
   built-in-Kotlin support. Fix: `android.builtInKotlin=false` + apply
   `org.jetbrains.kotlin.android` (Kotlin 2.3.21) + KSP 2.3.10.
3. **kotlin-android plugin vs AGP 9 new DSL** — `ApplicationExtensionImpl
   cannot be cast to BaseExtension`. Fix: `android.newDsl=false` (the error's
   own suggestion) + classic DSL syntax + file-level deprecation suppression.
4. **compileSdk mismatch** — Compose BOM 2026.02's lifecycle needs API 37;
   classic DSL can't say "36.1". Fix: `compileSdk = 37`.
5. **Duplicate google-services plugin** — catalog alias 4.4.4 + Firebase
   console's pasted `id(...) version "4.5.0"` line. Fix: single catalog entry
   bumped to 4.5.0.
6. **No Java on PATH for Gradle.** Fix: run with
   `JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"`.
